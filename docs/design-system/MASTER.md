# XProbe 设计系统 MASTER（M0 产出）

> **用途**：XProbe 前端所有 UI 实现的唯一视觉依据。M3 起任何组件样式不得偏离本文档；调整须先改这里。
> **生成**：2026-08-31（M0）。基线来自 ui-ux-pro-max 检索（`server monitoring dashboard dark glassmorphism` → Real-Time/Operations 模式 + Dark Mode OLED 风格），叠加 frontend-design / frontend-skill 原则校准。
> **校验**：全部文本/图形前景-背景组合经 WCAG 相对亮度公式计算，见 §3 对比度实测表。

## 1. 设计基调（Design Thesis）

**一句话**：深夜机房的克制仪表——深蓝夜幕上的毛玻璃仪表盘，数据是唯一的主角，色彩只用来表达状态。

- **气质（Tone）**：冷静、精确、专业。不炫技、不营销腔；标题与状态使用工具性文案（"在线 8/10""最近同步 12 秒前"）。
- **材质（Material）**：玻璃拟态卡片悬浮于深蓝渐变夜幕；光泽来自 `backdrop-blur` 与 1px 半透明描边，而非渐变堆砌。
- **能量（Energy）**：数据微动（圆环缓动、格子推入），界面本身静止。动效 150-300ms，全局尊重 `prefers-reduced-motion`。
- **差异化（Differentiation）**：
  - 延迟小格子是视觉签名——高度编码延迟值、颜色编码状态，一屏读完全部线路健康度；
  - 数字一律 `tabular-nums` 等宽，表盘般的对齐感；
  - accent 极度克制：默认界面近乎无彩（蓝灰），仅状态色（绿/黄/橙/红）与强调色出现。

**规避项**（frontend-design 禁忌 + 检索反模式）：紫渐变+白底、高饱和撞色、emoji 当图标（一律 SVG：Lucide/Heroicons）、装饰性动效、卡片马赛克堆砌（卡片仅在语义成立时使用）。

**与基线的偏差记录**：检索建议的 Fira Code/Fira Sans 走 Google Fonts 外链——被 CSP（`default-src 'self'`）与单二进制离线定位双重排除，改用系统字体栈（§4）。检索建议的浅色背景 `#F8FAFC` 仅作参考，实际采用冷灰蓝 `#F4F6FB`。

## 3. 字体与数字

| 用途 | 栈 | 说明 |
|------|-----|------|
| 正文/UI | `system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` | 系统栈，中英文混排优化；**不引入外部字体**（CSP + 离线） |
| 数字/指标/延迟值 | 同上 + `font-variant-numeric: tabular-nums` | 全部数值强制等宽（圆环中心、格子行尾、表格、tooltip） |
| 代码/ID/IP（详情页） | `ui-monospace, "Cascadia Mono", "JetBrains Mono", Consolas, monospace` | 本地等宽栈 |

字号阶梯：12（辅助）/ 13（正文次）/ 14（正文）/ 16（卡片指标标签）/ 20（圆环中心）/ 24（页面标题）。行高：正文 1.5，标题 1.25。

## 4. 几何与层次

| Token | 值 |
|-------|-----|
| 卡片圆角 | `rounded-2xl`（16px）；小元素 `rounded-lg`（8px） |
| 网格间距 | `gap-4`（16px）；卡片内边距 `p-5`（20px） |
| 分区 | 细分隔线（`--card-border`）或 12px 留白，不堆砌边框 |
| 玻璃质感 | `backdrop-blur-md`（12px）+ 半透明底 + 1px 描边 + 阴影 `0 8px 24px rgb(0 0 0 / 0.18)`（深色）/ `0 8px 24px rgb(15 23 42 / 0.08)`（浅色） |
| 悬停 | `hover:-translate-y-0.5` + 阴影加深，transition 200ms |
| 层级 | 背景(0) < 玻璃卡片(10) < 下拉/抽屉(30) < 弹窗(40) < Toast(50) |

## 5. 动效

| Token | 值 | 场景 |
|-------|-----|------|
| `--motion-fast` | 150ms | 悬停、按钮态 |
| `--motion-base` | 200ms | 卡片上浮、颜色过渡 |
| `--motion-slow` | 300ms | 圆环值更新、LatencyGrid 格子推入 |
| 缓动 | `cubic-bezier(0.2, 0, 0, 1)` | 全部 transition |
| 降级 | `@media (prefers-reduced-motion: reduce)` 下全部动画/过渡时长归零；主题设置"圆环动画=跟随系统"读此媒体查询 | — |

**数据更新不闪烁**：圆环用 `stroke-dashoffset` 过渡，数字用 `tabular-nums` 定宽；格子推入仅新格动画，旧格位移用整体容器过渡。

## 6. 核心组件规格（M3 实现依据）

### GlassCard
玻璃容器：`bg-card` + `backdrop-blur-md` + `border card-border` + `rounded-2xl` + §4 阴影。语义成立才用卡片（可点击进详情的节点卡、独立数据块的容器）；列表行、表单区不用卡片套卡片。

### RingProgress（64px SVG 圆环）
- 结构：底环（`--card-border` 色，4px）+ 值环（4px，`stroke-dashoffset` 按百分比）；中心 `tabular-nums` 20px 百分比；下方 12px 标签（CPU/内存/磁盘）。
- 颜色阈值：值环 <60% 用 `--success`，60-85% `--warning`，>85% `--danger`；离线显示 `--lat-6` 色 + 中心 `--`。
- CPU 首采样 `null`：中心显示 `--`，值环 0，不得显示 0%。

### LatencyGrid（延迟小格子）
- 每行 = 一个探测目标（`isp→region` 分组命名），行内 N=24 格；格子宽 6px 高 4-20px（按行内 max 归一化），圆角 1px，间距 2px。
- 颜色 = §2.3 阈值；高度 ∝ 延迟值；超时格用 `--lat-6` 且高度取行内最小。
- 悬停 tooltip：`时间 · 均值/最小/最大/抖动 · 丢包率`；行尾当前值（延迟+丢包，色 = 对应 lat 档，文字用"文字用"列色值）。
- 推入动画 300ms；reduced-motion 时直接替换。

### MiniBar（表格内 60px 迷你进度条）
高 6px 圆角 3px，底 `--card-border`，值段颜色同 RingProgress 阈值；`tabular-nums` 数值在右。

### 状态点（在线/离线）
8px 圆点 + 同色 24% 外圈光晕（box-shadow），在线 `--success`、离线 `--lat-6`。

## 7. 空/加载态（v1.3 规范）

| 场景 | 表现 |
|------|------|
| 首次加载 | shadcn Skeleton：卡片骨架（圆环圈 + 三条行）；禁止白屏/布局跳变 |
| 无服务器 | Empty：插图（简单 SVG 拓扑线稿）+ "添加第一台服务器" 主按钮 + 一键安装命令复制入口 |
| 无探测数据（目标停用/Agent 无 v6） | 行内显示 `无v6` / `未启用`，格子区灰条占位 |
| Agent 离线 | 卡片整体 opacity-60，圆环 `--`，格子全 `--lat-6` |
| 图表加载失败/WS 断开 | 顶部黄条"连接已断开，正在重连"，数据冻结不清空 |

## 8. 交互与可访问性基线

- 文案：工具性、状态导向（"在线 8/10"），不用营销腔；数字带单位（ms / MB·GB 自适应）。
- 图标：Lucide SVG，禁 emoji 图标（国旗 emoji 除外——它是数据本身）。
- 键盘：所有可点元素可 Tab 达；`focus-visible` 用 `--ring` 2px 轮廓 + 2px 偏移；卡片 Enter 进入详情。
- 触控目标 ≥44×44px；断点 375/768/1024/1440；除表格视图受控横向滚动外无横向滚动。
- 移动端：卡片单列、筛选收起为抽屉、表格受控横向滚动。
